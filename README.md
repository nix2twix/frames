# 🛡️ FRAMES: Система оценки устойчивости моделей компьютерного зрения к искажающим атакам

FRAMES (Face Recognition Attack Model Evaluation System) — это интерактивное веб-приложение для оценки устойчивости моделей векторизации лиц к искажающим атакам. Приложение позволяет генерировать состязательные примеры с помощью различных методов (FGSM, PGD, Carlini-Wagner, геометрическая атака), проводить количественную оценку и визуализировать результаты, а также экспортировать данные для дальнейшего анализа и дообучения моделей.

## ✨ Возможности

- 🧠 **Поддержка моделей**: предустановленная FaceNet (VGGFace2) и загрузка пользовательских PyTorch-моделей (state_dict + архитектура).
- 📁 **Загрузка данных**: встроенный датасет или загрузка собственного архива с изображениями лиц (ZIP).
- 🎯 **Сценарии атак**:
  - *Подмена личности* (impersonation) — достижение сходства с целевым изображением.
  - *Обход аутентификации* (deauthentication) — снижение сходства с исходным изображением.
- ⚔️ **Методы атак**:
  - FGSM (Fast Gradient Sign Method)
  - PGD (Projected Gradient Descent)
  - Carlini-Wagner (оптимизационная атака)
  - Геометрическая атака (деформация ключевых точек лица)
- 📊 **Метрики**:
  - ASR (Attack Success Rate) и Robustness (1 - ASR)
  - Нормы L0, L2, L∞
  - Косинусное сходство: S, S', ΔS, S_self, ΔS_self
  - Геометрические дескрипторы (6 нормированных признаков) и ΔGD
- 📈 **Серии экспериментов**: варьирование одного параметра атаки с автоматическим построением графиков.
- 🖼️ **Визуализация**: оригинал, состязательное изображение, тепловая карта различий, ключевые точки лица.
- 💾 **Экспорт**: CSV, PDF, HTML, архивы с состязательными изображениями, датасеты для дообучения, логи.
- 📝 **Логирование** всех экспериментов.

## 🚀 Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/<username>/frames.git
   cd frames
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## 🖥️ Использование

Запустите приложение:
```bash
streamlit run app.py
```

Приложение будет доступно по адресу [http://localhost:8501](http://localhost:8501).

### Интерфейс

1. **Общие настройки**:
   - Выбор модели (FaceNet или Custom).
   - Загрузка датасета (встроенный или ZIP-архив).
   - Настройка размера батча.
2. **Одиночный эксперимент**:
   - Выбор типа атаки и её параметров.
   - Выбор сценария (подмена личности / обход аутентификации).
   - Запуск атаки и просмотр результатов.
   - Экспорт метрик и визуализаций.
3. **Серия экспериментов**:
   - Выбор атаки и варьируемого параметра.
   - Задание диапазона и шага.
   - Запуск серии и анализ графиков.

## 📊 Метрики

Подробное описание метрик приведено в техническом задании. Кратко:

- **ASR** — доля успешных атак.
- **Rscore** — доля отражённых атак (1 - ASR).
- **L0** — количество изменённых пикселей.
- **L2** — евклидова норма возмущения.
- **L∞** — максимальное абсолютное изменение пикселя.
- **S** — косинусное сходство исходного и состязательного эмбеддингов.
- **S'** — косинусное сходство состязательного эмбеддинга с целевым.
- **ΔS** — изменение сходства с целевым эмбеддингом.
- **GD** — относительное изменение геометрических дескрипторов лица.
