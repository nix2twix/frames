# 🛡️ FRAMES

FRAMES (Face Recognition Attack Model Evaluation System) — это интерактивное веб-приложение для оценки устойчивости моделей векторизации лиц к искажающим атакам. Приложение позволяет генерировать состязательные примеры с помощью различных методов, проводить количественную оценку и визуализировать результаты, а также экспортировать данные для возможности дальнейшего анализа и дообучения моделей.

## ✨ Возможности

🧠 Использование предустановленной FaceNet (VGGFace2) и загрузка пользовательских PyTorch-моделей формирования векторных представлений лиц.

🎯 Доступны различные сценарии атак. Подмена личности (impersonation) — достижение сходства с целевым изображением. Обход аутентификации (deauthentication) — снижение сходства с исходным изображением.

⚔️ Реализованы методы атак:
  - FGSM (Fast Gradient Sign Method)
  - PGD (Projected Gradient Descent)
  - Carlini-Wagner (оптимизационная атака)
  - Геометрическая атака (деформация ключевых точек лица)

📊 Вычисляются показатели:
  - ASR (Attack Success Rate) и Robustness (1 - ASR)
  - Нормы L0, L2, L∞
  - Косинусное сходство: S, S', ΔS, S_self, ΔS_self
  - Геометрические дескрипторы

📈 Статистическая значимость путем запуска серии экспериментов с варьированием одного параметра атаки и автоматическим построением графиков.

## 🚀 Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/<username>/frames.git
   cd frames
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## 🖥️ Использование

Запустите приложение:
```bash
streamlit run app.py
```

Приложение будет доступно по адресу [http://localhost:8501](http://localhost:8501).
